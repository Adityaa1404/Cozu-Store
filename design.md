## Overview

Cozu Store is Indonesia's digital premium account marketplace — selling
subscriptions to Netflix, Spotify, YouTube Premium, Canva, and more. The
redesign replaces the borrowed Netflix-red identity with a distinctive
**teal-forward** palette that signals trust, freshness, and digital
sophistication.

**Brand personality:** Trustworthy · Modern · Friendly · Clean · Approachable

The visual system draws from Stripe's generous whitespace, Vercel's typographic
precision, and Wise's trust-building green accent — adapted for a warm,
Indonesian-audience-friendly tone. Light mode is the default canvas;
glassmorphism touches add depth without visual noise.

## Colors

### Brand Primary — Teal

- **Primary (#0D9488):** The brand anchor. Used on CTAs, active states, links,
  and key UI landmarks. Teal is ownable — distinct from competitor reds and
  blues, and culturally associated with trust and clarity.
  - WCAG AA on white: 3.4:1 (use for large text / icons only on white; pair
    with `on-primary` white text on teal backgrounds for 4.6:1 ✓).
- **Primary Dark (#0F766E):** Hover/active state for primary elements. AA on
  white: 4.8:1 ✓
- **Primary Light (#5EEAD4):** Decorative highlights, gradient endpoints,
  tag backgrounds. Not for text.
- **Primary 50 (#F0FDFA):** Tinted surface for subtle emphasis (selected rows,
  hover cards, badge backgrounds).

### Secondary — Indigo

- **Secondary (#6366F1):** Accent for secondary actions, visited links,
  illustrative elements. Provides contrast against the teal primary.
  AA on white: 3.8:1 (large text only on white; pair with white text for
  4.5:1 ✓).
- **Secondary Light (#A5B4FC):** Decorative, gradient use only.

### Tertiary — Amber

- **Tertiary (#F59E0B):** Attention and promotion — "sale" badges, price
  callouts, star ratings. High visibility.

### Glassmorphism

Frosted glass surfaces use:
```css
background: rgba(255, 255, 255, 0.72);
backdrop-filter: blur(16px) saturate(180%);
-webkit-backdrop-filter: blur(16px) saturate(180%);
border: 1px solid rgba(255, 255, 255, 0.3);
```

Apply to: sticky navbar, floating action buttons, cart drawer header.

## Do's and Don'ts

### Do

- **Use token references** (`{colors.primary}`) in component definitions.
- **Keep one primary CTA** per visible screen area.
- **Use the stone neutral scale** for all grays — never mix with
  slate/zinc/gray.
- **Apply glassmorphism sparingly** — navbar and one floating element max.
- **Test contrast** on every text-on-background combination before shipping.
- **Use Lucide icons exclusively** — no mixing icon sets.

### Don't

- **Don't use Netflix red (#E50914)** — it's not Cozu's color.
- **Don't rotate accent colors per app/tab** — teal is always the brand.
- **Don't use more than 3 border-radius values** on a single screen.
- **Don't apply shadows AND borders** on the same card — pick one.
- **Don't nest interactive elements** (button inside a clickable card).
- **Don't use `font-bold` (700) on body text** — reserve for headings.

## Responsive Strategy

### Mobile-First Approach

All styles are written mobile-first; larger breakpoints override upward.

### Component Adaptation

| Component       | Mobile (<768px)                     | Desktop (≥1024px)                   |
|----------------|-------------------------------------|--------------------------------------|
| Navbar          | Hidden; use mobile bottom nav       | Sticky glass bar, full links         |
| Product grid    | 2 columns, gap-3                    | 4 columns, gap-6                     |
| Hero            | Stack vertical, text-center         | Side-by-side, text-left              |
| Cards           | Full-width                          | Fixed-width in grid                  |
| Section padding | `py-16 px-4`                        | `py-24 px-8`                         |
| Modal           | Full-screen drawer (bottom sheet)   | Centered max-w-md                    |
| Typography h1   | 2rem                                | 3rem                                 |
| Typography h2   | 1.5rem                              | 2.25rem                              |
| Drawer          | Full-width bottom sheet             | Right sidebar max-w-md               |
| FAQ             | Single column                       | Two columns                          |

### Touch Target Minimums
